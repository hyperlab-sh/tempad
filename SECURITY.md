# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | Yes       |

## Reporting a Vulnerability

TemPad stores API tokens in a local `.env` and copies of private git repositories and Claude Code transcripts on disk. Anything that leaks those is a security issue.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/hyperlab-sh/tempad/security/advisories/new) or by email to me@saulo.engineer. Do not open a public issue.

You can expect an initial response within 48 hours.
